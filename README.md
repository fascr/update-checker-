# Fasmora Update Checker

A lightweight GitHub Pages update page that reads the live Fasmora update manifest from `Dancode-del/fasmora-updates/update.json`.

For exact installed-vs-latest comparison, open the page with `?versionCode=720&version=3.690.720`. Without a version code, the page shows the latest available release because normal web pages cannot read an installed Android app's version directly.
